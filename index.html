A FEW MORE THINGS

            

              Good questions.
Simple answers.
            

            Read the full documentation
          

          

            

              
                Is this the conference camera-ready version?
              
              

                Minnesota and Black modes create a Minnesota preprint with
                visible authors, no review line numbers, and long author rows
                that wrap to fit the page. For the official conference
                camera-ready layout, use \usepackage[off]{minnesotanlp} and
                your conference’s final setting, such as \iclrfinalcopy for ICLR.
              

            

            

              
                Do I need to clone the repo or install Python?
              
              

                No. Download and unzip the bundle, then upload the style file
                and two logos to your existing Overleaf project. No repository
                clone, Python installation, or template registration is needed.
              

            

            

              
                How do I make an anonymous submission?
              
              

                Switch to \usepackage[off]{minnesotanlp} and use your conference
                template’s review setting. [off] follows the conference’s
                existing settings. Minnesota and Black modes display author
                information.
              

            

            

              
                What changes in Black mode? How are captions aligned?
              
              

                \usepackage[black]{minnesotanlp} keeps the same layout and makes
                text accents black. Logo colors stay the same. In both Minnesota
                and Black modes, single-line figure and table captions are
                centered; longer captions are justified.
              

            

            

              
                Why aren’t the logos showing?
              
              

                Check that the logos folder is beside your main .tex file. It
                should contain university_of_minnesota_logo.png and
                minnesota_nlp_logo.png with their original filenames. If the
                images are missing, institutional names appear as text instead.
              

            

            

              
                Can I use another conference or a newer template?
              
              

                We’ve checked the six conference versions listed above and plain
                article. New versions need their own compatibility checks
                because title, author, and layout commands can change. To
                request support, open an issue with the conference name, year,
                and a link to its official template.
              

              Request another template↗
            

            

              
                What if I write my paper locally?
              
              

                Use the same three steps in your local paper folder: copy
                minnesotanlp.sty beside your main .tex file, keep both images in
                logos/, and add the package line. Compile from that folder using
                your conference template’s usual engine. For a pdfLaTeX project
                with latexmk installed, run:
              

              

                latexmk -pdf main.tex
